**Breaking: remove 17 unused exports from `@pie-qti/test-utils`** (beta prerelease). Repo-wide verification found zero consumers outside the package for the entire fixture-loader surface (`loadFixture`, `loadSharedFixture`, `loadFixtureBuffer`, `loadSharedFixtureBuffer`), six assertion helpers (`expectLosslessRoundTrip`, `expectValidChoiceInteraction`, `expectTransformError`, `expectMetadata`, `expectArrayContains`), the `MockPluginOptions` type re-export, the `createRejectingPlugin`/`createFailingPlugin` factories, the `CaptureLogger` and `ConsoleLogger` re-exports, and the `parseQtiItem`, `parseElement`, `createOutcomeDeclaration` QTI builders. The package's own tests and README were the only things keeping this surface green, and the README additionally documented a `createTestEngine` export that never existed. Tests that need these helpers already keep local copies where they are used (`to-pie/tests/test-utils.ts`, `item-player/tests/extraction/test-utils.ts`). Also removed the never-imported shared `fixtures/` directory. The remaining surface — `MockStorageBackend`, `MockTransformPlugin`, `createMockPlugin`, `SilentLogger`, `createQtiWrapper`, `createResponseDeclaration`, `createChoiceInteraction`, `expectValidPieModel`, `expectSuccessfulTransform` — is unchanged in behavior. `MockPluginOptions` remains exported from the plugin module (it is the `MockTransformPlugin` constructor's parameter type) but is no longer re-exported from the package entry.
