Internal consolidation, pinned behavior-identical by the extractors' existing tests. The duplicate-identifier validation loop that was inlined thirteen times across the eleven interaction extractors is now one shared `validateUniqueIdentifiers` (`src/extraction/utils.ts`), parameterized by the set's two message nouns ("source choices" / "source"); each extractor pushes the same errors with the same wording as before. The three private serialized-HTML attribute readers — stimulus docking (`stimulusRender`), gap-match prompt rewriting, and the feedback announcement — are now one shared `readHtmlAttribute` (`src/utils/htmlAttributes.ts`) with the most correct of the three shapes: quotes must pair, an empty value is present-and-empty rather than absent, a camelCase name also tries its kebab spelling (`outcomeIdentifier` or `outcome-identifier`), and values are returned untrimmed. Markup the loose stimulus reader mis-parsed (an unpaired quote such as `identifier="x'`, or `data-identifier` reading as `identifier`) now reads as absent — the strict reading was already the other two readers' contract — so stimulus docking of malformed tags could differ.
