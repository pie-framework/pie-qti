Round-6 interaction feedback fixes (WCAG 2.2 AA). Order and graphic-order confirmations keep their control mounted as an inert "Order confirmed" state (aria-disabled, focus retained) and announce the confirmation from an always-present polite region — the control used to be removed, dropping focus to the page. Graphic associate announces associations made, removed and refused, no longer sets `disabled` on the focused hotspot (aria-disabled plus a handler guard), and refocuses a surviving control after a pair removal. Remove/clear controls in match, gap match, graphic gap match, position object, hottext and file upload move focus to the related surviving control (now-enabled word/label/source, canvas, first hottext, native file input), and gap-match and file-upload announce the removal. Unmet minimums are now stated on the question: extended text states `minStrings` and refuses removing responses below it, graphic gap match states per-label `matchMin` honouring the authored `data-min-selections-message`, and graphic associate states `minAssociations` and per-hotspot `matchMin`. Rich text editors can re-edit inserted math from the keyboard (Enter/F2 beside the expression) and via an "Edit math" toolbar button, instead of pointer-only clicking. File upload translates every string with an English fallback (raw catalog keys could reach candidates) and resets the native input through a bound reference, so re-choosing the same file works even inside a shadow root. The PCI sandbox init payload gains optional `language`, `direction` and `frameTitle` fields, which the runner frame applies to its document (language, direction, title) before instantiating the interaction. All new strings ship in all 8 locales.
